# Power-Energy-Prediction ⚡

• Built using **Streamlit** for an interactive user interface <br>
• Implements an **Artificial Neural Network (ANN)** for prediction <br>
• Takes inputs: Ambient Temperature, Exhaust Vacuum, Ambient Pressure, Relative Humidity <br>
• Uses a pre-trained preprocessing pipeline with **Joblib** <br>
• Model loaded using **TensorFlow/Keras** <br>
• Generates real-time power energy output predictions <br>
Live Demo : https://power-energy-prediction.streamlit.app/ <br><br>
