# Power-Energy-Prediction ⚡
<br><br>
• Built using **Streamlit** for an interactive user interface <br><br>
• Implements an **Artificial Neural Network (ANN)** for prediction <br><br>
• Takes inputs: Ambient Temperature, Exhaust Vacuum, Ambient Pressure, Relative Humidity <br><br>
• Uses a pre-trained preprocessing pipeline with **Joblib** <br><br>
• Model loaded using **TensorFlow/Keras** <br><br>
• Generates real-time power energy output predictions <br><br>
Live Demo : https://power-energy-prediction.streamlit.app/ <br><br>
